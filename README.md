# Python Developer Portfolio

A semester-long Flask portfolio project for an introductory Python course.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Run all tests:

```bash
pytest
```

Run a single week's assignment tests:

```bash
pytest assignments/weekXX_*/
```

Students only edit Python files in `assignments/weekXX_*/starter.py`.
